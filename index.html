AI Security Prompting Guide

Prompt Engineering Best Practices

  • Be Explicit: State the exact system role (e.g., "Principal Application Security Engineer").
  • Define Boundaries: Provide negative constraints (e.g., "Do not test third-party endpoints").
  • Enforce Schema: Request output in standardized structure (e.g., Markdown table, JSON schema, Sigma format).
  • Supply Reference Snippets: Include source log files or exact code targets for higher precision.

AI Security & Model Risks

  • Prompt Injection: Occurs when untrusted data alters the model's intended instructions. Protect endpoints using delimiters (e.g., wrapping inputs in XML tags).
  • Data Confidentiality: Do not supply production API keys, production PII, or raw secret code to public commercial LLMs.
  • Hallucinations: LLMs generate plausible-sounding but false security findings. Always manually verify generated proof-of-concept scripts before execution.
